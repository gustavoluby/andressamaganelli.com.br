Banco de dados — Supabase

Conecte ao banco na nuvem para múltiplos usuários
Não configurado — dados apenas na memória
📋 Como configurar (5 minutos, gratuito):
  1. Acesse supabase.com e crie uma conta gratuita
  2. Clique em New project, dê um nome e escolha uma senha forte
  3. Aguarde o projeto ser criado (~1 min) e vá em Settings → API
  4. Copie a Project URL e a chave anon public e cole nos campos abaixo
  5. Vá em SQL Editor no menu lateral, cole o script abaixo e clique em Run
  6. Volte aqui, preencha as credenciais e clique em Testar e conectar
Script SQL — cole no Supabase → SQL Editor → New query:
create table if not exists processos (
  id bigint primary key,
  processo text,
  solicitacao text,
  tipo text,
  requerente text,
  situacao text,
  prazo date,
  obs text,
  abertura date,
  rodovia text,
  ocupacao text,
  lat numeric,
  lng numeric,
  created_at timestamptz default now()
);

alter table processos enable row level security;
create policy "acesso_publico" on processos
  for all using (true) with check (true);
